# GearSketch

Autodesk Fusion のスケッチ中に、任意モジュールのギアを描くアドインです。
スケッチの「作成」メニューに **GearSketch** (アイコン付きのサブメニュー) を追加し、その中に次の2つのコマンドが入ります。

- **平歯車 (モジュール指定)** — 選んだ点を中心にインボリュート平歯車を描く
- **ラック (モジュール指定)** — 選んだ線(または2点)に沿ってラックを描く

どちらも、拘束を付けない **固定形状** と、歯をまとめて1つのアイテムとして動かせる **パラメトリック** を選べます。
パラメトリックなら、相手のギアやラックとの位置合わせはピッチ円・ピッチ線に拘束を付けるだけで済みます。

## インストール

1. `git clone https://github.com/oumuika/GearSketch.git` で取得し、任意の場所に置く
   (ZIPでダウンロードした場合はフォルダ名が `GearSketch-main` になるので `GearSketch` に変更。
   Fusion はフォルダ名と `GearSketch.py` の名前が同じでないと読み込めません)
2. Fusion の **ユーティリティ → アドイン → スクリプトとアドイン** で「+」からこのフォルダを追加し、実行
3. 起動時に自動で読み込まれます (`runOnStartup: true`)

更新したときは、同じダイアログで GearSketch を **停止 → 実行** してください(Fusion は古いコードをメモリに保持し続けるため)。

## 平歯車

1. スケッチを編集中に **作成 → GearSketch → 平歯車 (モジュール指定)**
2. 中心にする **点** (または円。円ならその中心) を選ぶ
3. 作り方・モジュール・歯数などを入力して OK

### 作り方は2種類

| モード | 特徴 |
|---|---|
| **固定形状 (既定)** | 全部の歯をそのまま描く。拘束・寸法は付かず軽い。中心点とピッチ円だけ共有 |
| **パラメトリック (まとめて動く)** | 歯1枚を中心点と歯の中心線に対して拘束し、円形パターンで並べる。中心を動かすと移動、中心線を回すと回転、歯をドラッグすると一体で動く |

### できるもの

- 歯面はインボリュート曲線 (スプライン近似。誤差はモジュール 1 で 0.001 mm 未満)
- 歯底は歯元R (既定 0.38m) で歯底円と歯面に接続
- 圧力角・転位係数・歯末/歯元のたけ係数・歯厚減少量 (バックラッシ用) を指定可能
- 軸穴 (直径を指定、0 でなし)
- 補助線として **ピッチ円** を作成 (パラメトリックでは **歯の中心線** = 中心から1枚目の歯の中心を通る線 も作成)

### 動かし方・噛み合わせ方 (パラメトリック)

- 中心点を動かすと移動、歯の中心線を回すと回転。歯をドラッグすると全体が一体で動きます
- 2つの平歯車を噛み合わせるには、**ピッチ円どうしを接線拘束** します (中心距離が m×(z1+z2)/2 になる)
- ラックと噛み合わせるには、**ラックのピッチ線とギアのピッチ円を接線拘束** します
- 歯の位相 (歯と歯溝が向かい合うか) は、歯の中心線の角度を寸法や拘束で決めて合わせてください

### 変更するとき

歯数・モジュールなどを変えるときは、ギアの線 (どの歯でも可) を選んでコマンドを再実行します。
設定が読み込まれ、OK で **同じ中心点・中心線・ピッチ円のまま** 作り直します。
ピッチ円や中心線に付けた拘束 (相手ギアとの接線拘束など) はそのまま残ります。
作り直すときに固定形状とパラメトリックを切り替えることもできます。

## ラック

1. スケッチを編集中に **作成 → GearSketch → ラック (モジュール指定)**
2. 基準にする線を1本、または始点と終点の2点を選ぶ
3. モジュールなどを入力して OK

### 作り方は2種類

| モード | 特徴 |
|---|---|
| **パラメトリック (まとめて動く)** | 歯1枚を拘束で定義し、ピッチ線方向の関連付きパターンで並べる。ピッチ線を動かす・歯をドラッグすると **ラック全体が一体で動く**。歯数はユーザーパラメータ `RackN_N` で変更可能。長さは「歯数 × ピッチ」(両端は歯溝の中心) |
| **固定形状 (両端で正確に切る)** | 選んだ2点の位置で歯形を正確に切る。拘束は付かない |

- 選んだ線を **ピッチ線 / 歯底線 / 歯先線** のどれとして扱うか選択できます
- 背面まで閉じた輪郭にすれば、そのまま押し出し可能
- モジュールや圧力角を変えるときは、ラックの線を選んでコマンドを再実行 (同じピッチ線上に作り直し)

### オプションの補足

- **歯の位置をピッチ線の始点に連動**: オンで歯の並びがピッチ線に対して決まる(ピッチ線と一体で動く)。オフにするとピッチ線に沿ってスライドもできる。スケッチ上に固定する機能ではありません
- **作成した線をその場に固定**(詳細): 固定形状モード専用。まとめて動かしたいときはオフのまま

## 制限

- 平歯車: 歯数が少ないときの切り下げ (アンダーカット) は再現していません (基礎円より内側は半径方向の直線)
- ラック: 歯形は標準基準ラック(直線歯面)。パラメトリックモードでは歯数は整数。歯先Rは固定形状モードのみ
- Fusion のスケッチソルバーでは、モジュール等の大きな変更を寸法変更だけで追従させると解けなくなるため、作り直し方式にしています。作り直すとプロファイルを参照していた押し出しは選び直しが必要になる場合があります

## 動作確認

Fusion 2706.1.17 (Windows)
